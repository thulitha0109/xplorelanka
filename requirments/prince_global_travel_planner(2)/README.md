# Prince Global Travel Planner

Modern tourism platform vision by Prince Place Cabins.

## Features
- Tour planning
- Eco accommodation booking
- Nearby place discovery
- Vehicle live tracking
- Community travel events
- Future global tourism expansion

## How to Run

1. Create a React + Vite project:
npm create vite@latest

2. Install Tailwind CSS

3. Replace App.jsx with the included file

4. Run:
npm install
npm run dev
